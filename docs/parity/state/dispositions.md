# ferrum-state dispositions (proposed)

> What: proposed disposition of every cm6 export. Versions: cm6 `@codemirror/state` 6.7.6 (`mirrors/cm6/state/package.json`); Ferrum line numbers at commit `fb99ca1` (`crates/` unchanged through `ed70610`). Ids: id schemes and path rules in `docs/parity/README.md`.

Proposals for human approval (brief section 3). One row per cm6 export row of `docs/parity/state/raw/a1-cm6-exports.md` (264) and per cm6 source file (13).

Common ground for every `CORE` row: `@codemirror/state` has no DOM, CSS or browser dependency (its only dependency is `@marijn/find-cluster-break`, `mirrors/cm6/state/package.json`), and nothing in `state/src` touches `document`, `window` or layout. Every item is therefore platform-independent logic; the reason column says what the item does for a native editor and flags decision dependencies.

JSON items (`toJSON`/`fromJSON`) are proposed `CORE` because the scope sheet asks for them and they are needed for persistence and for `collab`; decision D10 could move them to `DEFER`.
