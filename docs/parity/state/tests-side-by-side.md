> What: every cm6 test case mapped to Ferrum tests, with verdicts. Versions: cm6 `@codemirror/state` 6.7.6 (`CodeMirror6/state/package.json`); Ferrum line numbers at commit `fb99ca1` (`ferrum/crates/` unchanged through `ed70610`). Ids: id schemes and path rules in `ferrum/docs/parity/README.md`.

Merged from `ferrum/docs/parity/state/raw/C1-tests.md` … `ferrum/docs/parity/state/raw/C6-tests.md`. Mapping is by behavior: each Ferrum test body was compared with the cm6 case body (inputs, assertions, expected values). cm6 has no `webtest-*` files in `@codemirror/state`, so the `LOGIC-ONLY`/`NEEDS LAYOUT`/`DOM-ONLY` classification does not apply to this crate.
