# C6 tests (rangeset)

Totals: cm6 cases owned 47 (`state/test/test-rangeset.ts`), Ferrum tests owned 47 (`crates/ferrum-state/src/tests/test_rangeset.rs`).

Method: I opened both test bodies and compared them line by line. As extra evidence, `repro-C6/src/bin/cm6tests.rs` ("Replay", R33 in `C6-api.md`) re-runs every cm6 case with cm6's exact inputs and expected values against Ferrum's public API. Replay results are quoted per row; they are audit evidence, not Ferrum tests.

cm6 helper defaults matter for the "inputs" comparisons: cm6 `Value` has `startSide = spec.startSide ?? 1`, `endSide = spec.endSide ?? spec.startSide ?? (empty ? 1 : -1)`, `point = empty || spec.point`, and `eq` by `name` (`state/test/test-rangeset.ts:10-20`). Ferrum `TestVal::mark(name, s, e)` takes explicit sides (most tests pass 0, 0); `TestVal::point` = sides 1/1, point; `TestVal::with_pos` = sides 1/−1, non-point (`crates/ferrum-state/src/tests/test_rangeset.rs:20-50`).
